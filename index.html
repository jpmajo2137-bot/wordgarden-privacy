한눈에 보기

  • 워드가든은 개인정보를 수집하지 않습니다. 회원가입, 로그인, 광고, 분석 도구가 없습니다.
  • 학습 기록은 사용자의 기기 안에만 저장되며, 개발자를 포함한 누구에게도 전송되지 않습니다.

1. 기기에 저장되는 정보

학습 진도(단어별 복습 단계와 다음 복습 시각), 학습일 기록, 즐겨찾기, 설정(하루 학습량, 발음, 테마 등)은 앱이 동작하는 데 필요해 기기의 앱 저장소에만 보관됩니다. 이 정보는 외부 서버로 보내지지 않으며, 앱을 삭제하거나 설정의 ‘학습 기록 초기화’를 누르면 지워집니다.

2. 백업 파일

설정의 ‘백업 내보내기’를 누르면 학습 기록이 JSON 파일로 기기에 저장됩니다. 이 파일을 어디에 보관하거나 공유할지는 사용자가 직접 정하며, 워드가든은 이 파일을 어디로도 보내지 않습니다.

3. 발음 기능

영어 발음은 기기에 설치된 음성 합성(TTS) 엔진으로 재생됩니다. 워드가든은 단어나 문장 텍스트만 기기의 TTS 엔진에 전달하며, 음성 녹음이나 마이크를 사용하지 않습니다. TTS 엔진의 동작은 해당 엔진 제공자(예: Google)의 정책을 따릅니다.

4. 권한

워드가든은 위치, 연락처, 카메라, 마이크, 저장소 등 민감한 권한을 요청하지 않습니다.

5. 제3자 제공 및 광고

개인정보를 제3자에게 제공하거나 판매하지 않으며, 광고 SDK나 분석 SDK를 포함하지 않습니다.

6. 아동

워드가든은 개인정보를 수집하지 않으므로 아동의 개인정보도 수집하지 않습니다.

7. 변경
